# ystack contributor map

This is the compatibility entry point for agents that read AGENTS.md. See [GEMINI.md](GEMINI.md) for repository instructions and [architecture](docs/ARCHITECTURE.md) for the public approach.

- **Scope:** this selected repository only; do not inspect unrelated local projects or global private configuration.
- **Current starter:** vnext/skills/ystack-{bootstrap,verify,ship}/SKILL.md and scripts/bootstrap-project.sh.
- **Legacy:** swarmstack/, config/bootstrap.md, old dispatch scripts, and mcp/settings.json are historical, not recommended setup.
- **Build:** smallest working result, one agent by default; specialists only when independently useful.
- **Verify:** focused evidence for this revision; separately report real Preview/provider/release checks.
- **Permissions:** no automatic destructive actions, external messages, credential changes, production deployment, or merges.
- **Documentation:** distinguish implemented work, static checks, prototypes, and future plans.

Never overwrite a consumer project's existing AGENTS.md or GEMINI.md.
