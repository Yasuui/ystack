# [Project name] — local contract template

This is **an outline**, never a reason to replace an existing project's instructions.

## Objective
- Product purpose: [one sentence]
- This task: [observable result]
- Done when: [two to four acceptance criteria]

## Scope
- Work only in: [explicit selected repo root]
- Read relevant existing files; do not scan sibling repos or private global settings.
- Preserve current CI, deployment, auth, database, and development conventions.
- Out of scope: [explicit non-goals]
- Do not touch: [sensitive or unrelated paths]

## Workflow
- One implementation agent unless truly independent work with non-overlapping files is justified.
- Make the smallest working change; focused checks before expanded testing.
- Change evidence is not real Preview, provider, or production proof.
- FAST / DEFAULT / HIGH / ESCALATE / STRONGEST are effort tiers, not hardcoded models.

## Approval boundaries
- No external sends, production deploys, destructive migrations, credential updates, or merges without relevant approval.

## Handoff
Report the files changed, actual checks and results, remaining release gates, and the next meaningful action. Stop once acceptance criteria are met.
